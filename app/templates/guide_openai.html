API Key 발급 및 사용 가이드

Eng2Mouth 는 내 키로 실시간 음성 통화와 말하기 평가를 실행합니다. Gemini 와 OpenAI 중 하나만 있어도 됩니다.

Google Gemini (저렴 · 무료 티어)

  1. Google AI Studio → Get API key 에서 구글 계정으로 로그인 후 Create API key 를 누릅니다. 결제 등록 없이도 무료 티어로 바로 사용할 수 있습니다.
  2. 생성된 AIza… 키를 설정 → Gemini API Key 에 붙여 넣고 "키 확인"을 누르면 접근 가능한 Live 모델을 자동으로 찾습니다.
  3. 무료 티어는 분당 요청 수와 하루 사용량에 제한이 있습니다. 한도에 걸리면 "요청 한도" 오류가 나며, Google Cloud 결제를 연결하면 유료 티어로 제한이 풀립니다.

비용 감 (유료 티어 기준 추정): 통화 10분 약 $0.12~0.35 · 평가 1회 약 $0.003 (Gemini 2.5 Flash).

OpenAI (가장 사람 같은 목소리)

1OpenAI 계정 만들기

이미 ChatGPT 계정이 있다면 그대로 사용합니다. platform.openai.com/signup

2결제 수단 등록 & 크레딧 충전

API 는 ChatGPT Plus 와 별개로 사용량만큼 과금됩니다. 결제 페이지 에서 $5~10 정도 충전하면 충분히 시작할 수 있습니다.

3API Key 만들기

API Keys 페이지 → Create new secret key. 이름은 "Eng2Mouth" 처럼 적어두세요.

키는 생성 직후 한 번만 보입니다. 바로 복사하세요.

4Eng2Mouth 설정에 붙여넣기

설정 → OpenAI API Key 칸에 sk-… 키를 붙여 넣으면 자동 저장되고, "키 확인" 버튼으로 모델 접근 여부를 검사할 수 있습니다.

키는 서버 DB 에 본인 계정에만 저장되며, 통화 시 10분짜리 임시 토큰을 만드는 데만 쓰입니다. 브라우저에는 실제 키가 전달되지 않습니다.

비용 감 잡기 (참고용 추정)

  • gpt-realtime 통화 10분: 대략 $0.3~0.6 (말을 많이 할수록, 상대가 길게 말할수록 증가)
  • gpt-realtime-mini 통화 10분: 대략 $0.1~0.2
  • 통화 후 평가 리포트 1회: $0.005~0.02 · 힌트/번역 1회: $0.001 미만

정확한 금액은 OpenAI 사용량 대시보드를 확인하세요. 앱의 누적 사용 금액은 공개 단가 기준 추정치입니다.
